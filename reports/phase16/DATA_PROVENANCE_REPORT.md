## 1. THE SIX DATA PROVENANCE CATEGORIES

In natural hazard intelligence, blending different data types into an undifferentiated risk score destroys scientific validity. To guarantee absolute transparency, HAZARDX AI tags every data payload with one of six provenance classes:

```
1. VERIFIED LIVE OBSERVATION
   - Ground-truth telemetry recorded within the last 3 hours by physical sensors or satellites.
   - Examples: USGS seismic station trigger, NASA VIIRS 375m fire pixel, NHC aircraft recon vortex fix.

2. NUMERICAL FORECAST (NWP)
   - Physics-based atmospheric/hydrological model projections from statutory weather services.
   - Examples: ECMWF IFS 24h precipitation grid, GloFAS 3-day river discharge simulation.

3. MACHINE LEARNING PREDICTION
   - Statistical inference generated by HAZARDX AI's trained XGBoost models.
   - Examples: Flood occurrence probability (0.82), Cyclone 24h intensity change (+18 kt).

4. HISTORICAL OBSERVATION
   - Ground-truth catalog records from past disaster events.
   - Examples: IBTrACS cyclone archive (1980–2026), NASA Global Landslide Catalog (1996–2017).

5. EXPERIMENTAL MODEL OUTPUT
   - Model predictions with moderate holdout skill (R² ~ 0.22 - 0.34); advisory guidance only.
   - Examples: Max aftershock magnitude estimate (Mw), Wildfire Fire Radiative Power (FRP).

6. DEMONSTRATION / SCENARIO DATA
   - Reconstructed historical profiles or illustrative test overlays used for disaster drill simulations.
   - Explicitly tagged with `is_demonstration: true`; strictly segregated from live siren channels.
```

## 2. GEOGRAPHIC DATA QUALITY & COORDINATE BOUNDARIES

Geographic coordinates are strictly validated across all ingestion and prediction endpoints using Pydantic Field constraints:

```python
latitude: float = Field(..., ge=-90.0, le=90.0, description="WGS84 Latitude (-90 to +90 degrees)")
longitude: float = Field(..., ge=-180.0, le=180.0, description="WGS84 Longitude (-180 to +180 degrees)")
```

### Coordinate & Measurement Boundary Enforcement:
1. **Latitude/Longitude Out-of-Bounds:** Any coordinate with $|\text{lat}| > 90.0$ or $|\text{lon}| > 180.0$ is rejected immediately with HTTP 422 Unprocessable Content.
2. **Physical Measurement Boundaries:**
   - Wind speed: $10.0 \le V \le 220.0\text{ kt}$. Impossible negative or supersonic winds are rejected.
   - Central pressure: $850.0 \le P \le 1030.0\text{ hPa}$.
   - Relative humidity: $0.0 \le \text{RH} \le 100.0\%$.
   - Earthquake magnitude: $1.0 \le M \le 10.0$.
   - Focal depth: $0.0 \le \text{depth} \le 750.0\text{ km}$.
