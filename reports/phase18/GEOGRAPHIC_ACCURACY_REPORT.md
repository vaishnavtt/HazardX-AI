## 1. CARTOGRAPHIC REFERENCE SYSTEMS & PROJECTIONS

Geographic data in HAZARDX AI strictly conforms to international geospatial standards:
1. **Internal Storage & GeoJSON API Payloads:** Standard Geographic WGS84 (EPSG:4326). Coordinates are represented as `[longitude, latitude]` in GeoJSON geometries and `(lat, lon)` in tabular schemas.
2. **Client-Side Rendering Projection:** Spherical Web Mercator (EPSG:3857) projected by Leaflet tiles.
3. **Distance Calculations:** Spherical Haversine metric formula:
   $$d = 2 R \arcsin \left( \sqrt{\sin^2\left(\frac{\Delta \phi}{2}\right) + \cos \phi_1 \cos \phi_2 \sin^2\left(\frac{\Delta \lambda}{2}\right)} \right)$$
   Where $R = 6,371.0\text{ km}$. Linear planar approximations ($dx^2 + dy^2$) are strictly prohibited for global distance calculations.

## 2. STRICT DISAMBIGUATION OF MAP OVERLAYS

A critical hazard in disaster cartography is presenting static, unverified, or decorative polygons as active emergency zones. In strict adherence to Phase 18 guidelines, every overlay on the HAZARDX AI map is explicitly labeled with one of five cartographic classifications:

```
+-------------------------------------------------------------------------------------------------+
| 1. ACTUAL OBSERVED EVENT LOCATION                                                               |
|    - Verified physical sensor detection recorded by an official scientific agency.              |
|    - Visual Style: Solid pulsing circle marker with exact magnitude/FRP label.                  |
|    - Examples: USGS M 5.2 epicenter, NASA VIIRS 375m active fire detection pixel.               |
+-------------------------------------------------------------------------------------------------+
| 2. OFFICIAL STATUTORY WARNING AREA                                                              |
|    - Administrative warning boundary published by a national civil defense authority.           |
|    - Visual Style: Heavy dashed outline with official agency badge (e.g. NOAA NHC Storm Surge). |
+-------------------------------------------------------------------------------------------------+
| 3. MODEL-DERIVED RISK ESTIMATE                                                                  |
|    - Predictive spatial field generated by HAZARDX AI machine learning inference.               |
|    - Visual Style: Translucent color-coded heat surface (0.25 opacity) labeled "AI Risk Field". |
+-------------------------------------------------------------------------------------------------+
| 4. STATIC SUSCEPTIBILITY ZONE                                                                   |
|    - Invariable terrain baseline indicating geological or hydrological vulnerability.           |
|    - Visual Style: Faint cross-hatched background fill labeled "Baseline Susceptibility".        |
|    - Examples: USGS Active Fault Buffer (15 km), FEMA 100-year River Floodplain.                |
+-------------------------------------------------------------------------------------------------+
| 5. ILLUSTRATIVE / DRILL OVERLAY                                                                 |
|    - Synthetic boundary used for disaster management training scenarios.                       |
|    - Visual Style: Monochromatic slate polygon explicitly watermarked "SCENARIO DRILL ONLY".    |
+-------------------------------------------------------------------------------------------------+
```

### Governance Rule Enforced:
> **"Do not display static illustrative polygons as live danger zones."**
Static fault lines and river basins are never styled in flashing emergency red unless accompanied by a verified live sensor alert.

## 3. GEOMETRIC VALIDATION & BOUNDARY INTEGRITY

In `backend/app/api/v1/endpoints/geospatial.py`, all GeoJSON payloads undergo topological validation:
- **Coordinate Order:** Verified strictly as `[longitude, latitude]` in GeoJSON coordinate tuples, preventing inverted coordinate axes.
- **Ring Closure:** All polygon rings explicitly close on their initial vertex ($P_0 = P_n$).
- **Anti-Meridian Wrapping:** Tracks crossing the International Date Line ($\pm 180^\circ$) are correctly split into multi-part geometries to prevent artificial horizontal lines across the Pacific basin.
- **Coordinate Clipping:** Latitude is hard-clipped to $[-85.0511^\circ, +85.0511^\circ]$ for Web Mercator conformal projection bounds.
